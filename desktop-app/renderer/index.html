    授权码获取指引
    不同邮箱入口略有差异，按下列步骤查找“授权码 / 应用专用密码”。
    Gmail / Google
    1. 打开 Google 账号管理页 → 安全性
    2. 启用两步验证
    3. 生成“应用专用密码”
    4. 将生成的 16 位密码填入授权码
    图示：应用专用密码
    QQ 邮箱
    1. 进入 QQ 邮箱 → 设置 → 账户
    2. 找到“POP3/IMAP/SMTP服务”
    3. 开启服务并生成授权码
    4. 复制授权码粘贴到这里
    图示：SMTP 授权码
    163 / 126 邮箱
    1. 邮箱设置 → POP3/SMTP/IMAP
    2. 开启 SMTP 服务并生成授权码
    3. 记录生成的授权码
    4. 填入授权码栏
    图示：开启 SMTP
    Outlook / Office365
    1. 账号安全设置 → 应用密码
    2. 开启两步验证（若未开启）
    3. 生成应用密码并保存
    4. 将应用密码填入授权码
    图示：应用密码
    提示：SMTP 登录失败通常是授权码错误或未开启 SMTP 服务。
    Gmail API credentials.json 获取指引
    用于 Gmail API（443）授权，不是 SMTP 授权码。
    步骤 1：创建 Google Cloud 项目
    1. 打开 Google Cloud Console
    2. 新建项目或选择已有项目
    3. 确认项目已启用结算（若需要）
    步骤 2：启用 Gmail API
    1. 进入“API 和服务” → “库”
    2. 搜索 Gmail API 并点击启用
    3. 等待 API 启用完成
    步骤 3：配置 OAuth 同意屏幕
    1. 进入“OAuth 同意屏幕”
    2. 应用类型选 External
    3. 填写应用名和支持邮箱并保存
    步骤 4：创建 OAuth 客户端
    1. 进入“凭据” → “创建凭据” → “OAuth 客户端 ID”
    2. 应用类型选 Desktop app
    3. 创建后下载 JSON 文件
    4. 在账号中心点击“上传 credentials.json”导入该文件
    提示：每个 Gmail 账号首次绑定都会打开 Google 登录授权页，完成后本地会保存独立 token。
